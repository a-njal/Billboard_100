Billboard Hot 100 Songs Finder (Spotify API)
📌 Project Overview
This project retrieves the Billboard Hot 100 songs for a user-specified year and finds them on Spotify using the Spotify Web API. It creates a playlist of these songs, allowing users to explore the top hits from any given year easily.

🚀 Features
✅ Fetches Billboard Hot 100 songs for a given year
✅ Uses Spotify API to search for songs and fetch details
✅ Creates a Spotify playlist with the top 100 songs
✅ Generates a structured dataset of the songs

🛠️ Technologies Used
Python
Spotify Web API (Spotipy library)
BeautifulSoup (for web scraping Billboard 100)
Requests
Pandas
